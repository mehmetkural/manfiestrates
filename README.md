# Manifest – Instagram Takipçi Cinsiyet Oranı

Turkish girl group Manifest üyelerinin Instagram takipçi cinsiyet dağılımını (Kadın / Erkek) gösteren statik bir GitHub Pages sitesi.

**Canlı Site:** https://mehmetkural.github.io/manfiestrates

## Özellikler

- Her 15 dakikada bir simüle güncelleme (±2% rastgele dalgalanma)
- Gerçek zamanlı geri sayım sayacı
- Güncelleme sırasında animasyonlu flash efekti
- Mobil uyumlu, saf HTML/CSS/JS

## Üyeler

| Sueda Uluca | %78 | %22 |
| Zeynep Sude Oktay | %73 | %27 |

> Veriler şu an için simüle edilmektedir. Gerçek API entegrasyonu için `index.html` içindeki `baseline` objesini ve `tick()` fonksiyonunu güncelle.

## GitHub Pages Kurulumu

1. Repo → **Settings → Pages**
2. Source: **Deploy from a branch**
3. Branch: `main` / `/ (root)` → **Save**

## Geliştirme

Derleme adımı yoktur. `index.html` dosyasını doğrudan tarayıcıda aç.
